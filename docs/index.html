This URL is stored in this browser's local storage. Use HTTPS for a deployed API. The API must allow this website's origin using CORS. Provider secrets must be backend environment variables. External lookups can share submitted indicators with third parties; public deployments need abuse controls, durable rate limits, quotas, and monitoring.
